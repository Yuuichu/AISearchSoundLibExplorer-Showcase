# REAPER 集成

检索引擎只有在编辑的那一刻能够触达才有用。REAPER 客户端的存在，是为了让设计师在不离开 DAW、也不切到浏览器的情况下完成搜索、试听与插入。

## 前置条件

- **ReaImGui 0.10+**，通过 ReaPack 安装（「ReaImGui: ReaScript binding for Dear ImGui」）。如果缺失，脚本会带着明确错误快速失败，而不是静默降级。
- 检索后端在本地运行（`python -m sfx serve`）。

## 客户端做什么

- **检索模式**可在 UI 中切换（默认 `hybrid`），与 API 的 `keyword` / `semantic` / `hybrid` 模式一致。
- **预览**通过 REAPER 自带的预览能力实现，并带有显式的停止路径，因此预览不会被留在播放状态。
- **从某条结果发起相似音频检索。**
- **收藏**，用于标记有用的命中。
- **插入**整个文件，以及按匹配时间范围做**片段插入**——这是片段级索引的回报。
- **键盘导航**，包括可停靠上下文（`ConfigFlags_DockingEnable`）与键盘导航标志，因此它的行为像工具，而不是模态对话框。

## 网络约束

客户端**只连接回环 HTTP**。它不是远程客户端，也不接受任意的后端 URL：音效库是客户素材或授权素材，检索工具没有理由访问本机之外的地方。

## 为什么非要有 DAW 客户端

因为真正的竞争者其实是另一套工作流：Alt-Tab 切到浏览器、输入查询、听结果、再切换回来、在媒体浏览器里找到文件、拖进来、然后裁剪到正确的时刻。客户端消除了来回切换，而有了片段插入，连手工裁剪也一并消除了。

## 选录源码

`selected-code/AI_SFX_Explorer.lua` 是 ReaImGui 入口点——上下文创建、状态，以及预览停止路径。辅助性的 `lib/api.lua`（回环 HTTP 客户端）与 `lib/json.lua` 未收录，因为它们是小型工具，而不是有意思的部分。
